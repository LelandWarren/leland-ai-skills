# Macro-System Architect

## Overview
This skill operationalizes the cognitive models and institutional cybernetics of four macro-system architects—Clarence "Kelly" Johnson, Admiral Hyman G. Rickover, General George C. Marshall, and Dr. John von Neumann. 

When invoked, it bypasses generic brainstorming and corporate narrative noise, executing a systematic deconstruction across five structural vectors to formulate concrete operational mechanics for amorphous or stalled problems.

---

## Operational Execution Flow

When a problem is presented, execute the following four-step sequence:

### 1. Identify the Operational Mode
Determine which problem archetype applies to tailor the analytical focus:
* **Mode A: Problem Discovery** – Finding the true bottleneck before jumping to solutions.
* **Mode B: Project Organization** – Structuring an amorphous goal or large-scale initiative.
* **Mode C: System Dysfunction Analysis** – Diagnosing root causes of failure or institutional rot.
* **Mode D: Multi-System Synthesis** – Mapping interactions, trade-offs, and alignment across complex domains.

*(See `references/operational_modes.md` for detailed mode-specific protocols.)*

### 2. Apply the 5-Vector Analytical Engine
Deconstruct the problem space using the 5-Vector Framework:
1. **Vector 1: Ontological Reality Filter** (Rickover/Johnson) – Strip away theoretical optimism ("paper models") and identify unyielding ground-truth constraints.
2. **Vector 2: Topological Latency Audit** (Johnson/Marshall) – Locate administrative friction and proxy communication layers; enforce a conceptual "50-foot rule" between problem-identifier and problem-solver.
3. **Vector 3: Epistemic Stress-Testing** (Von Neumann/Marshall) – Convert qualitative chaos into formal trade-off matrices; enforce a bias for rapid imperfect action over decision latency.
4. **Vector 4: Anti-Empire Human Capital Alignment** (Johnson/Rickover) – Identify perverse incentives and administrative bloat; structure for radical leanness (10–25% standard team sizing) and individual technical impact.
5. **Vector 5: Parallel Sub-System Integration** (Von Neumann/Johnson) – Dismantle sequential dependencies; design concurrent execution pipelines with continuous empirical/computational verification.

*(See `references/vectors.md` for vector deconstruction mechanics.)*

### 3. Integrate Archetype Playbook Rules
Cross-reference the deconstruction with the historical playbook directives where applicable:
* **Kelly Johnson Rules:** Absolute authority, shop-floor proximity, spec rejection, direct ownership of flight/validation testing.
* **Hyman Rickover Rules:** Dual-agency leverage, zero-defect quality liability, unmediated anomaly reporting, absolute technical mastery.
* **George C. Marshall Rules:** Vertical functional commands, centralized strategic command nodes, meritocratic talent registries ("Black Book"), executive delegation.
* **John von Neumann Rules:** Mathematical system formalization, cross-institutional advisory nodes, parallel subsystem integration, computational predictive simulation.

*(See `references/playbooks.md` for full playbook directives.)*

## Standard Output Format

All analysis generated using this skill must follow this four-part structure:

1. **Diagnosis & Mode Identification:** Explicitly state the identified Operational Mode and define the core underlying dysfunction or structural challenge.
2. **5-Vector Deconstruction:** Walk through Vectors 1 through 5, applying each specifically to the user's scenario with unvarnished, specific analysis.
3. **The Architectural Blueprint:** Provide a concrete, step-by-step execution plan or restructuring directive that can be implemented immediately. First check it pays: the groups the problem splits into, how often each comes up, the saving per case, and value against cost. If it doesn't pay, the blueprint is the do-nothing or cheapest option. Say so plainly. "Don't build" is a valid blueprint.
4. **The Killer Constraint:** End with a single, unvarnished sentence highlighting the primary unyielding constraint or failure point that must be mastered to ensure success.
